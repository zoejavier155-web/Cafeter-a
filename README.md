# Cafeteria
# Descripcion del proyecto:
Desarrollo de una plataforma web interna para la cafetería universitaria, de uso exclusivo para los empleados. Su objetivo es optimizar la atención mediante la consulta rápida del catálogo de alimentos y bebidas, el registro digital de pedidos y el seguimiento en tiempo real de las órdenes pendientes y finalizadas, garantizando un servicio más ágil y un control eficiente de las ventas.
# Descripcion del problema:
Durante los horarios de alta demanda, el registro manual o verbal de pedidos provoca confusiones, errores en las cantidades, retrasos en la preparación y pérdida de información. La ausencia de un menú centralizado y digitalizado enlentece la atención al cliente, mientras que la falta de un sistema automatizado para ordenar las comandas dificulta que cocina atienda los pedidos en estricto orden de llegada y complica la administración general del inventario y las ventas.
